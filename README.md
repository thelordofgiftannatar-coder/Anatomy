# The Oath Keeper
Audiobook player for PC. It remembers every book you played, the chapter, and the exact second you stopped.

- Quick try: double-click `index.html` (Chrome or Edge). Your progress is kept, but you must re-add the files after closing.
- Desktop app: `npm install` then `npm start`, or let GitHub build the .exe (Actions > Build The Oath Keeper for Windows > download the artifact).
- Keys: Space play/pause, Left back 15 s, Right forward 30 s. Keyboard media keys work too.
